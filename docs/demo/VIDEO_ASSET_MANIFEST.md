# VIDEO-01 video asset manifest

Reviewed 2026-10-27. These are licensed prerecorded films, not installed cameras. Camera names are demo locations. Original filming dates are not local Veyra replay/ingest dates. No person or organization shown endorses Veyra.

Seven real sources are available: six default cameras and one unregistered source reserved for the connect-camera demonstration. Six originals were downloaded for VIDEO-01; the existing Henry Geer original was reused and verified. Every acquisition used the official Wikimedia Commons file API/CDN, and all seven originals were checked against the published SHA-1. Pinned SHA-256 values below identify the exact local bytes. Machine-readable acquisition/trim recipes: [video-sources.json](video-sources.json).

## Scope

The actual footage does not establish parcel deliveries, private-driveway parking, a residential lobby or a security incident. Those desired scenarios remain future asset requests. The reserved station original is only 10 seconds; it is not duplicated into a falsely claimed 20-second original event. All default films are 20.6–36 seconds. Original files and prepared media stay in ignored local runtime storage; the pinned source recipes support a clean download/preparation on another machine.
